# Ujjawal Ranjan Portfolio
## Local
npm install && npm run dev
## Deploy to Vercel
Push to GitHub, import the repo at vercel.com (framework: Vite, build `npm run build`, output `dist`). No env vars needed.
## Editing
Content: src/data/content.js. Replace public/resume.pdf. Set `demo`/`github`/`image` on projects (null hides buttons).
